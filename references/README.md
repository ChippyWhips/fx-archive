# Visual references

Read alongside `BRIEF.md` (Visual direction section). Take the qualities described, not the layout, content or branding of any reference. My notes in the brief take precedence over anything in these images.

## Do

| File                                        | What it is                                                                            | What to take from it                                                                                                                                                                                                                                                             |
| ------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `do/01-museum-department-project-page.png`  | Museum Department single project page ([site](https://museumdepartment.com/projects)) | The effect page structure: huge, heavy, centred uppercase title; three-block information row (metadata, related details, overview text); lead visual at full width below. Bold sans labels over grey mono values.                                                                |
| `do/02-radial-ticks-accordion-dark.png`     | Dark process diagram with a stacked accordion list                                    | Two-line list items (title plus grey subtext), the single small accent dot for active state, the precision of the radial tick-mark drawing, calm dark surfaces.                                                                                                                  |
| `do/03-hairline-slider-panel-light.png`     | Light control panel over a line pattern                                               | Row-based controls: label left, value right in mono; hairline dividers; hairline sliders with a heavier fill; dimmed inactive rows; swatch plus hex for colour; small rectangular toggle; rotary dials. **Ignore the frosted-glass panel** (panels must be solid).               |
| `do/04-pill-buttons-slider-panel-light.png` | Light panel with oversized pill buttons                                               | Oversized, fully rounded primary buttons with generous padding; minimal sliders with the value to the right. **Ignore the icons inside the buttons** (buttons are text only).                                                                                                    |
| `do/05-component-sheet-light.png`           | Light component sheet ("Quivox")                                                      | Instrument-style inputs: tick-mark ruler scrubber with the value in a chip, +/− steppers, segmented options, mono for numbers. **Ignore the decorative glyph icons** beside list items.                                                                                          |
| `do/06-grouped-generator-panel-dark.png`    | Dark generator tool with grouped controls beside the canvas                           | Named control groups with sentence-case titles; rows with hairline dividers; slider plus right-aligned mono value; the sidebar pattern (controls left, canvas right). Note the accent colour and all-mono uppercase labels here are _not_ adopted wholesale: mono is for values. |

## Don't

| File                                | What it is                             | Why to avoid it                                                                                                                                                                                                                          |
| ----------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dont/01-dense-default-widgets.png` | Dense, default-styled control panel    | Cramped rows, default OS widgets (selects, × checkboxes), and four competing alignment columns that make it slow to scan.                                                                                                                |
| `dont/02-all-mono-uppercase.png`    | Stylised all-mono, uppercase panel     | Mono and uppercase used for everything, plus tight spacing and boxes around every option. Everything looks the same, so the hierarchy flattens and it can't be chunked visually.                                                         |
| `dont/03-generic-design-system.png` | Rounded grey component panel ("ASCII") | Looks like a generic design-system component kit (Figma/Framer style): filled grey inputs, stacked grey layers, soft rounding on every element, default chevron dropdowns, blue focus ring, app-style header with icon and close button. |
