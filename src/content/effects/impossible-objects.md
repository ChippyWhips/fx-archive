## How it works

On paper, an impossible object is just an inconsistent drawing. In 3D it has to be built as a trick, and the trick is the same one used in the large physical tribar sculptures: make an open shape that only closes from one point of view.

Here the shape is three beams laid end to end along x, then y, then z. In an orthographic view looking straight down the (1, 1, 1) diagonal, those three axes project to lines 120° apart, so the path appears to come back to where it started, and the far end of the last beam lands exactly on top of the first. That alone gives the wrong overlap at the final corner, with the last beam covering the first. So the last beam is cut: the shader discards any part of it whose line of sight along the diagonal passes through the first beam. From the magic viewpoint the first beam now shows through precisely where it should, and the corner reads as a clean joint.

Shading carries the rest. Every face is filled with one flat tone according to which axis it faces, the convention of the classic drawings. Because the three tones never change round the loop, the eye has no local reason to doubt any corner.

## Brand tool lens

The parameters that define the look are the viewpoint, the beam proportions and the three tones, and all of them should be locked. Lock the projection too: the illusion only exists in a parallel view, and a perspective camera gives it away at the far corner.

What is worth exposing is time. An identity built on an impossible mark can use the swing as its signature motion: hold, open, close. Expose the hold and the reveal angle within a tight range, and keep turn speed and easing fixed, so every version breaks and reassembles in the same way.

For example, a logotype set on an impossible tribar could ship as a still mark plus a two-second reveal for social, both generated by the same tool from the same locked geometry.

## Easily confused with

**Ambiguous figures**, like the Necker cube, have two valid readings and flip between them. An impossible object has no valid reading at all.

**Anamorphosis** distorts an image so it only looks right from one place. It shares the single-viewpoint trick, but the object being depicted is possible.

**Escher-style tessellation** is a different strand of Escher's work: tiles that interlock and transform. It is about the plane, not about contradictory depth.

**Forced perspective** misjudges size and distance rather than topology. The scene is consistent; only the scale is misread.
